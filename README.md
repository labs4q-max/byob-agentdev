# BYOB with AI — Your First Inbox Assistant

**Start here: [Open the copy-and-paste exercise](START-HERE.md).**

Build a useful business assistant entirely in chat. Paste one block, get three draft replies, check them, and keep the instructions for your own business.

No coding, API keys, inbox connection, or file downloads are required. You need access to an AI chat tool. This exercise demonstrates an agent-style workflow; it does not run in the background or send email.

## The quick path

1. Open [START-HERE.md](START-HERE.md).
2. Copy the exercise block into a new AI chat and send it.
3. Review the results using the three checks on that page.
4. Save or copy your replies using the [responses folder](responses/README.md).

## Can't download?

Open a Markdown file and copy the text directly from the page. Markdown is just plain text with simple headings. You can paste into chat or a notes app; no GitHub editing or technical setup is required.

Use the fictional examples in class. Keep real customer details and your own responses out of this public repository.
