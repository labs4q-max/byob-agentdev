# Responses — Copy, Compare, and Keep

1. Run the exercise in [Start Here](../START-HERE.md).
2. Read [example-responses.md](example-responses.md) to compare your result.
3. Open [my-responses-template.md](my-responses-template.md), copy the worksheet, and paste it into your notes.
4. Paste your own drafts into the worksheet and record any edits or owner decisions.

## If downloading does not work

Open the file and select the text directly on the page. If the page offers a **Raw** view, you can use that to copy plain text. Paste it into chat, a text editor, or a notes app. Saving a file is optional.

If you do save it, use a name such as `my-responses.md` in your own `responses` folder. A `.txt` file or a note also works.

This public folder contains sample responses and a blank template. Your AI chat does not automatically save here. Keep your own responses private; no GitHub upload is needed.

## The three checks

- **Tone:** Does this sound like the business?
- **Facts:** Does every claim match the supplied notes?
- **Next step:** Is it clear what the customer or owner should do?

When a draft needs an owner decision, leave it marked **Needs owner review**. A polished reply is not proof that an order was checked or an action was completed.
